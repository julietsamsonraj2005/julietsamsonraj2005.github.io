How I build

HEALTH AI, one layer at a time.

How my AI health-risk prediction system is structured, from what the user sees to where the data lives.

Layer 1

Interface

A React front end where a person enters their health parameters and sees the predicted risk.

Layer 2

API

Secure REST APIs built with FastAPI or Flask carry each request between the interface, the model and the database.

Layer 3

Model

A Random Forest model trained with Scikit-learn on health parameters predicts the health risk.

Layer 4

Data

MongoDB stores the data, keeping storage separate from the rest of the system.
